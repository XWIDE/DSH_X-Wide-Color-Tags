# dsh-xwide-color-tags

给 DeepSeek Harness 侧栏的每个会话打颜色标签：一眼分出「这条在跟什么活」。两条入口——右键会话的菜单色板，和会话行左端的小圆点弹板。选中后该会话行左侧出现同色竖条、标题染同色。

纯前端插件，零运行时依赖，只写浏览器 `localStorage`，不碰宿主任何配置文件。

## 用法

### 1. 右键会话 → 「会话颜色」色板

- **4 个预设色**：荧光黄 `#ffc300`、荧光绿 `#2ecc71`、荧光青 `#00c8ff`、荧光粉 `#ff63c5`。
- **彩虹块**：打开自绘取色面板（见第 4 条）。
- **✕ 清除**：只在当前会话已上色时出现，清掉这个会话的颜色。
- 色块样式取自 `dsh-xwide-annotation` 的「批注配色」：32×32、圆角 9px、选中加白色 2px 描边；彩虹块同款 conic 渐变。

### 2. 会话行左端的小圆点

- 已上色的会话行左端有一枚 10px 小圆点，颜色＝该会话的颜色。
- **点圆点**开弹板（同一排色块）；圆点带白色描边＝当前正在用的颜色。
- 弹板是浮动层，带 `data-context-menu-trigger="1"`，不会被宿主的全局按钮样式扫描改写。

### 3. 右键＝取消（弹板里一套统一机制）

| 你在弹板里按右键的位置 | 发生什么 |
|---|---|
| 预设色块 / 彩虹块 | 取消这个会话的颜色，并收板 |
| 「我的颜色」里的自定义色块 | 删掉这一个自定义色（面板原地重画，当场少一格），会话颜色不动 |
| 弹板空白处 / ✕ 按钮 | 收板（✕ 同时清掉会话颜色） |

每个块的悬停提示都写着它这一按会干什么，形如 `#ff63c5（右键＝删除这个自定义色）`、`荧光黄（右键＝取消颜色）`。

### 4. 彩虹块＝自绘 HSV 取色面板

不用系统取色盘（样式不可控、也不可调明度饱和度），插件自绘：

- 左边一块 **明度/饱和度方格**，右边一条 **色相条**，下方一条 **明度滑条**，外加当前色预览。
- **取色**＝把当前颜色加进「我的颜色」并立即应用到这个会话；**确定**＝只入「我的颜色」；**取消**＝什么都不写。
- 入队的颜色**按 hex 去重**（同色不重复占位），**最多保留最近 8 个**，超出的从队头挤掉。

### 5. 恢复默认

「我的颜色」非空时，弹板末尾出现 **「恢复默认」** 按钮：点一下清空整排自定义色，弹板原地重画。

- 它**不动会话颜色**——那是你正在用的标记，清它会话颜色请用 ✕。
- 没有二次确认（清空不可撤销），要留色请先别按。

## 存储

只写浏览器 localStorage，键名前缀 `xwcolor.`：

| 键 | 内容 |
|---|---|
| `xwcolor.map` | `{ sessionId: "#rrggbb" }` 会话 → 颜色 |
| `xwcolor.customs` | 「我的颜色」列表（最近 8 个） |
| `xwcolor.probe` | 自检记录：会话行选择器命中情况（见下） |

## 已知限制（读数说话，不粉饰）

- **端口换＝存储换。** 桌面端 GUI 的本地端口每次重启都会变，而浏览器存储是按 origin（含端口）分家的。实测本机连换三次端口后，`xwcolor.*` 落在旧 origin 里读不到，表现就是「颜色和自定义色像回到了默认」。这是宿主的 origin 行为，**插件侧目前没有做迁移**。
- **会话行 DOM 形状未实盘验证。** 开发时真机界面带鉴权（返回 401），无头浏览器读不到登录后的页面；上色效果、菜单项在页面上的呈现，全部证据来自无头浏览器的真 DOM 断言，**没在真人界面上逐条验收过**。
- **清空自定义色不可撤销**，且没有「只删这一个之外的全部」这类批量选择。

## 与 Codex UI 的关系

已核对 `@michengai/dsh-codex-ui` 2.3.0：它的全局按钮改样式扫描排除 `[data-context-menu-trigger]`、`[aria-haspopup="menu"]`、`[data-row-key]`。本插件的色块一律带 `data-context-menu-trigger="1"` + `role="menuitem"`，因此落在它的排除名单里，不被改样式；槽位用它没有占的 `sidebar.workspaces.session.menu.item`（order 900，在「归档」之前、Codex UI 未读项 order 150 之后）。

## 自检

插件启动时会把候选选择器的命中数与前 3 个 key 样本写进 `localStorage["xwcolor.probe"]`，形如：

```json
{ "ts": 1730000000000, "found": { "[data-row-key]": { "count": 12, "sampleKeys": ["session-abc", "..."] } } }
```

- 哪个选择器 `count > 0` 且 `sampleKeys` 长得像 sessionId → 上色就会生效。
- 全是 `count: 0` 或 `(nokey)` → 菜单能选色、存色，但行上不上色；把这段读数发出来即可定位真实选择器。

## 安装 / 卸载

- 安装：`npm i dsh-xwide-color-tags`，或在 profile 的 `local-plugins\` 下放本目录并在 `cordis.patch.yml` 加装载行。
- 卸载：删除本目录 + 移除 profile 里的装载行与 junction；`xwcolor.*` 三个键留在 localStorage，不留残留文件。
